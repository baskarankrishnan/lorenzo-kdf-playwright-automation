#### 4. Element Naming Conventions
- `txt_*` = Textbox input fields
- `cmb_*` = Combobox dropdowns
- `btn_*` = Button elements
- `lbl_*` = Label/text display
- `ico_*` = Icon elements
- `chk_*` = Checkbox
- `lnk_*` = Hyperlink
- `tbl_*` = Table
- `dte_*` = Date picker field
- `rad_*` = Radio button

### Dynamic Elements with `<variable>`
Elements with `<variable>` in xpath use **ElementText** column for substitution:
```json
{"element": "lnkTaskPaneMyWork", "xpath": "//span[text()='<variable>']"}
```
**Usage:** `Element=lnkTaskPaneMyWork, ElementText=Inpatient` → xpath becomes `//span[text()='Inpatient']`

## 📊 KDF (Keyword-Driven Framework) Format

### JSON KDF Structure (11-Column Format)
Each test step contains:
```json
{
  "StepNo": 1,
  "StepDescription": "Clear action description",
  "Page": "pageLogin",
  "Element": "txt_username",
  "ElementText": "Username TextBox",
  "ActionKeyword": "setTextBox",
  "Property": "value",
  "Condition": "equals",
  "TableColumnNames": "",
  "Values": "USERNAME",
  "DatasetColumnName": "USERNAME"
}
```

### Excel Test Case Structure (4 Sheets)

**Sheet 1: TestExecution**
- All 11 KDF columns
- Bold headers with gray background (RGB: 211, 211, 211)
- One row per test step

**Sheet 2: TestData**
- Columns: Variable, Category, Value, Description
- Lists all test data variables
- Organized by category (Authentication, Patient, Referral, etc.)

**Sheet 3: ExecutionConfig**
- Test Case ID, Module, Sub-Module, Description
- Complexity, Priority, Estimated Duration
- Total Steps, Pages Used, Elements
- Prerequisites, Assertions, Author, Dates

**Sheet 4: TestValues**
- Test iterations (minimum 2)
- Variable substitution for each iteration
- Different test data per iteration

### Common ActionKeywords

| Keyword | Purpose | Values Format |
|---------|---------|---|
| `navigateToUrl` | Launch application | URL string |
| `login` | User authentication | "username\|password" |
| `setTextBox` | Fill text field | Text or variable name |
| `selectComboBox` | Select dropdown | Option text or "Index_0" |
| `clickElement` | Click element | (empty) |
| `handleDialog` | Dialog response | "0\|Yes", "0\|No", etc. |
| `waitForRoller` | Wait for loading | (empty) |

### ActionKeyword Mapping by Element Type (ActionKeyword_Lorenzo_2.json)
| Prefix | Element Type | Valid ActionKeywords |
|--------|--------------|---------------------|
| `txt_` | TextBox | `setTextBox`, `clearTextBox`, `getText`, `verifyProperty` |
| `btn_` | Button | `clickElement`, `dblClickElement`, `verifyProperty` |
| `cmb_` | ComboBox | `selectComboBox`, `setComboBox`, `clearComboBox`, `selectComboByIndex` |
| `chk_` | Checkbox | `setCheckBox`, `clickElement`, `verifyProperty` |
| `tbl_` | Table | `selectRecordInTable`, `getCellData`, `verifyRecordInTable` |
| `lnk_` | Link | `clickElement`, `getText`, `verifyProperty` |
| `lbl_` | Label | `getText`, `getTextAndStorePASID`, `clickElement` |

**Keywords NOT requiring Element:** `login`, `logout`, `waitForRoller`, `waitForSeconds`, `handleDialog`
**Keywords NOT requiring Page:** `launchUrl`, `getRandomValue`, `getPastDateTime`, `setVariable`
| `verifyElementText` | Assert text | Expected text |
| `getTextAndStorePASID` | Capture data | "_" for capture |
| `getPastDateTime` | Generate past date | "_current\|1D\|DD/MM/YYYY\|_dtmPast1Day" |

## 🔄 Workflow: Creating New Test Cases

### Step 1: Create JSON KDF File
Create `KDF_<WorkflowName>.json` in `kdf-generation/kdf-scripts/`

```json
[
  {
    "StepNo": 1,
    "StepDescription": "Navigate to Lorenzo application",
    "Page": "pageLogin",
    "Element": "app_LorenzoLoginPage",
    "ElementText": "Lorenzo Application",
    "ActionKeyword": "navigateToUrl",
    "Property": "URL",
    "Condition": "",
    "TableColumnNames": "",
    "Values": "http://dxcappchne8097a.cscidp.net/webclient_sso/extlogon.aspx?idp=oidnatlogon&IsClientInfoNotRequired=true",
    "DatasetColumnName": "LAUNCH_URL"
  }
  // ... more steps
]
```

### Step 2: Create PowerShell Generator Script
Create `generate_<workflow>_excel.ps1` following this pattern:

```powershell
# Paths
$scriptDir = $PSScriptRoot
$kdfRoot = Split-Path -Parent $scriptDir
$jsonFilePath = Join-Path (Join-Path (Join-Path $kdfRoot "kdf-generation") "kdf-scripts") "KDF_<WorkflowName>.json"
$outputPath = Join-Path (Join-Path (Join-Path (Join-Path $kdfRoot "excelFramework") "testcases") "<Module>") "<FileName>.xlsx"

# Load JSON and create Excel
$json = Get-Content -Path $jsonFilePath -Raw | ConvertFrom-Json
$steps = $json

# ... [Create Excel workbook with 4 sheets]

# Save
$workbook.SaveAs([System.IO.Path]::GetFullPath($outputPath))
```

### Step 3: Execute PowerShell Script
```powershell
powershell -ExecutionPolicy Bypass -File "C:\path\to\generate_<workflow>_excel.ps1"
```

Result: Excel file created in appropriate module folder with 4 sheets
