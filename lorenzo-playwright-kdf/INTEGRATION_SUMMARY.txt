🔄 LOCATOR RESOLUTION FLOW
═══════════════════════════════════════════════════════════════════════════════

When Test Runs:
  1. Framework reads .env
  2. Sees LOCATOR_REPOSITORY_SOURCE = pages
  3. Calls readLocatorRepositoryFromPages('./pages')
  4. Dynamically imports all 216 page JS files
  5. Extracts all XPath exports
  6. Builds locator repository object
  7. Stores in executionContext
  8. Test step references page + element
  9. Framework looks up XPath from repository
  10. Uses XPath to find and interact with element
  11. Test continues

Result: ✅ Fast, reliable, dynamically loaded element locators

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Pages not loading
  → Check .env: LOCATOR_REPOSITORY_SOURCE = pages
  → Check ./pages directory exists
  → Run: npm run validate

Problem: Element not found in test
  → Verify page name is correct (case-sensitive)
  → Verify element name is correct (case-sensitive)
  → Run: npm run validate (check if page/element listed)
  → Check page file for element definition

Problem: XPath not matching element
  → Test XPath in browser DevTools
  → Check for dynamic element attributes
  → Verify element hasn't moved on page
  → Check for iframe or shadow DOM

Problem: Tests running slowly
  → Page loading happens once, then cached
  → Check network connectivity
  → Verify Playwright installation
  → Run: npm test with --debug flag
